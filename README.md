# 🎉 Gather & Glow – Event Management Website

### Make Every Moment Matter!

## 📌 About the Project

Gather & Glow is a modern and elegant Event Management website designed to help people plan and organize memorable celebrations.

The website showcases different event management services, including weddings, birthday parties, and corporate events. It focuses on creative ideas, beautiful decorations, proper coordination, and stress-free event planning.

## ✨ Features

- **Wedding Celebrations:** Beautiful decorations, event coordination, and personalized wedding arrangements.
- **Birthday Parties:** Creative themes, attractive decorations, and memorable birthday celebrations.
- **Corporate Events:** Professional planning for business meetings, launches, and team events.
- **Our Services:** Easy access to different event management services.
- **Contact Section:** Contact details for event enquiries and bookings.
- **Responsive Design:** A clean and user-friendly website interface.

## 🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling, layouts, and visual design.
- JavaScript – Interactive functionality (if implemented).
